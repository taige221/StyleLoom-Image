# 05 电影剧照质感

由外层 [SKILL.md](../SKILL.md) 选择后按需读取；共享内容约束、图片类型、参考图处理、工具调用与留档规则由外层负责。

## 风格提示词

将指定内容呈现为电影剧照般的摄影画面。光照具有明确方向和层次，在符合指定环境的基础上，用亮暗关系、色彩分离和焦点组织引导视线。主体与背景处于统一的光照及色调体系中，保留可信材质和适量成像纹理。通过光影、空间和焦点形成叙事感，不自动添加雾气、霓虹、暗角或宽银幕黑边。

## 核心关系

有组织的光影、空间层次和焦点共同形成剧照观感。

## 使用边界

- 电影感不自动等于夜景、低调曝光、青橙调色或宽画幅。
- 保持摄影式成像；若用户明确要动漫电影或三维电影画面，不能仅凭电影一词选本预设。
