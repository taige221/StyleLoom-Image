## Style prompt (English, primary)

Render the specified content as handmade felt and textile imagery. Keep forms soft but structured, with visible short fibers, felted texture, and natural edges. Fiber direction, separated color regions, and soft contact shadows should explain volume while preserving specified facial features, markings, and object relationships. Retain crafted detail rather than making every object the same fuzzy ball or hiding key features beneath long fur. Do not automatically substitute button eyes, generic doll faces, or decorative stitching.

## 中文参照（不用于拼接）

将指定内容表现为毛毡织物手作图像。形体柔软而有结构，表面可见细短纤维、毡化纹理和自然边缘。用纤维方向、色块分区及柔和接触阴影共同表达体积，保留指定五官、花纹与物体关系。细节具有手工制作感，避免所有对象都变成相同毛球，或用长绒毛遮住关键特征。

## 核心关系

纤维表面、柔软轮廓和色块分区共同形成有结构的手作体积。

## 使用边界

- 与 18 区分：使用纤维及毡化表面，而非黏土压痕。
- 不默认替换成纽扣眼睛、统一玩偶脸或增加缝线装饰。
