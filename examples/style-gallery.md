One representative image per style, numbered 01–30. Scenes, models, and prompt revisions vary across these existing samples; use them as visual references. Historical samples use earlier Chinese prompts. Each entry links to the current English style preset.

Images are lossless WebP copies at their original dimensions, verified pixel-for-pixel against the generated PNGs. / 展示图为原尺寸无损 WebP，已核对与原始 PNG 的解码像素一致。
