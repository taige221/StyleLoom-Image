# 验证摘要

本文件保留可随项目分发的文字结论，不依赖本机图片、绝对路径或被 Git 忽略的产物。记录日期：2026-11-26。

## 历史图像实验

实验选择 OpenRouter 的 `bytedance-seed/seedream-5-5`，并不构成 StyleLoom Image 的默认模型或 API 配置。

| 项目 | 结果 |
|---|---|
| 首轮请求 | 8 张，API 返回费用 $0.160 |
| 完整补测 | 新增 46 张，API 返回费用 $1.008；复用首轮 8 张 |
| 正式用例覆盖 | 30 个风格用例＋18 个能力用例，共 48 个 |
| 辅助产物 | 5 张虚构参考素材＋1 张明确悬浮关系的超现实正向补测 |
| 图片总数 | 54 张原始 PNG，约 80.4 MB |
| 累计已知费用 | $1.168，均来自 API 返回值 |
| 参考图输入 | 11 张次，包括一个三参考图分工用例 |
| 输出档位 | 各用例一张 1K；未在本轮比较原生高分辨率、JPEG或重复稳定性 |

用户粗看整批图后反馈：作为第一版，整体风格区分度还不错。该反馈支持保留当前 30 种风格继续迭代，不代表每项内容、中文文字、身份保持或编辑准确性已经逐项通过验收。

图片未被载入聊天上下文。技术检查包括文件解码、尺寸、哈希、输入文件绑定、费用，以及透明底样图是否具有真实透明与可见像素；这些检查不替代画面评价。参考素材为专门生成的虚构人物、宠物、服装和场景，不能代替真实用户参考图的效果验证。

本机首轮和补测产物分别位于 `output/seedream-5.5-pilot-2026-11-26/` 与 `output/seedream-5.5-complete-2026-11-26/`。这些目录不会随仓库分发，缺失时不影响 Skill 使用。用例内容见 [测试提示词模板](test-prompts.md)。

## 正式执行器与目录验证

历史生图实验使用了独立的临时脚本。当前 [正式执行器](../scripts/generate.py) 将协议、地址和模型配置外置，已使用模拟响应覆盖文生图、参考图、编辑上传、原生文件保存、费用留档、密钥脱敏、失败不重试及透明通道检查。

项目补充了预设与索引一致性、相对链接可分发性、示例任务及用途元数据测试。统一运行：

```bash
python3 -m unittest discover -s tests -v
```

这些离线测试不产生外部绘图费用，不将实验图片放入上下文。正式执行器尚未进行新的真实付费 API 调用，也未做跨供应商效果或性价比排名。

## 后续验收

- 使用用户选择的外部连接配置，对正式执行器做小量真实接口验收。
- 人工核对参考图前提、主体特征、文字、分镜状态与编辑保留项。
- 对不稳定的用例按同一输入重复测试，再计算实际可用率和每张可用图成本。
- 新增的 6 份用途预设已接入选择与留档；历史用例包含相关用途，但不作为这些新文件的独立视觉对照验证。

测试计划与当前缺口不应被写成已通过的质量结论。
